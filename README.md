## Install · 安装

| You use · 你在用 | Do this · 这样装 |
|---|---|
| Claude Code · Codex · Cursor · Copilot · Gemini CLI · OpenCode · Kimi · Qwen … (75+) | `npx skills add QingBo-AI/skills --skill <name>` |
| Everything at once · 全装 | `npx skills add QingBo-AI/skills --skill '*'` |
| WorkBuddy | Paste the skill's folder link and say "install this skill" · 把技能目录链接丢给它说「安装这个 skill」 |
| 豆包 · 元宝 · ChatGPT · any chat with no skill system | Open the skill's `PROMPT.md` → copy → paste at the start of your chat · 打开 `PROMPT.md` 复制粘贴到对话开头 |

Pick a specific agent with `-a`, e.g. `npx skills add QingBo-AI/skills --skill <name> -a codex`.
Nothing to sign up for. Nothing published to npm. Skills are pulled straight from this repo.

## Catalog · 目录

Every entry ships three files: `SKILL.md` (for agents), `PROMPT.md` (copy-paste version), `README.md` (how to use it, with examples). Collected skills also carry a `SOURCE.md` crediting the original author and license.

每个条目三件套：`SKILL.md`（给 agent 装）、`PROMPT.md`（复制粘贴版）、`README.md`（怎么用 + 示例）。收录条目另有 `SOURCE.md` 注明原作者与许可。
